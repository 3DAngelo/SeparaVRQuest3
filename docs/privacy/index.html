Separa VR Rosario

Privacy Policy

Effective date: November 13, 2026

This policy covers the app Separa VR Rosario for Meta Quest and this website, both from 3DAngelo, an independent developer in Rosario, Argentina.

In short

The app does not collect, store, transmit or share any personal data. It has no account or registration, no ads, no analytics, no crash-reporting SDKs and no in-app purchases.

Hand tracking

The app uses the headset's hand tracking so you can grab objects. Hand tracking data is processed on the device by the Meta Quest system to drive the in-game hands. The app does not record, store or send it anywhere.

Permissions

The app requests these Android permissions:

  • com.oculus.permission.HAND_TRACKING: to use hand tracking.
  • android.permission.INTERNET: included by default by the game engine. The app itself makes no network requests to the developer or to third parties.

Data saved between sessions

None. No progress, scores or identifiers are stored.

Children

The app is suitable for general audiences. Since no personal data is collected, none is collected from children. Meta's own account age requirements for the headset apply.

Meta platform

Meta may collect data as the operator of the platform and store, under its own policy: Meta Privacy Policy. That is separate from this app.

This website

This site is made of static pages. It uses no cookies and no trackers. It is hosted on GitHub Pages, and GitHub may log technical data such as IP addresses, as described in the GitHub General Privacy Statement.

Data deletion requests

Because nothing is collected, there is nothing to delete. If you have any question, write to gregoriodangelo@gmail.com.

Changes to this policy

If this policy changes, it will be updated on this page with a new effective date.
