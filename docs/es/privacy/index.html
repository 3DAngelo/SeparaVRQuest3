Separa VR Rosario

Política de privacidad

Fecha de vigencia: 13 de noviembre de 2026

Esta política abarca la aplicación Separa VR Rosario para Meta Quest y este sitio web. La aplicación es un desarrollo de la Municipalidad de Rosario, Argentina, que la publica en la Meta Horizon Store.

En resumen

La aplicación no recopila, almacena, transmite ni comparte ningún dato personal. No tiene cuenta ni registro, ni publicidad, ni analíticas, ni SDK de reporte de fallos, ni compras dentro de la aplicación.

Seguimiento de manos

La aplicación usa el seguimiento de manos del visor para que puedas agarrar objetos. Los datos del seguimiento de manos los procesa el sistema de Meta Quest en el propio dispositivo para mover las manos dentro del juego. La aplicación no los graba, no los almacena ni los envía a ningún lado.

Permisos

La aplicación solicita estos permisos de Android:

  • com.oculus.permission.HAND_TRACKING: para usar el seguimiento de manos.
  • android.permission.INTERNET: lo incluye por defecto el motor del juego. La aplicación en sí no hace ninguna solicitud de red al desarrollador ni a terceros.
  • org.khronos.openxr.permission.OPENXR y org.khronos.openxr.permission.OPENXR_SYSTEM: para conectarse con el runtime de OpenXR del visor, el componente del sistema que ejecuta las aplicaciones de realidad virtual. No dan acceso a datos personales.

Datos guardados entre sesiones

Ninguno. No se almacena ningún progreso, puntaje ni identificador.

Niños y niñas

La aplicación es apta para todo público. Como no se recopilan datos personales, tampoco se recopilan de niños y niñas. Rigen los requisitos de edad de la cuenta de Meta para el visor.

Plataforma de Meta

Meta puede recopilar datos como operador de la plataforma y de la tienda, según su propia política: Política de privacidad de Meta. Eso es algo separado de esta aplicación.

Este sitio web

Este sitio está hecho de páginas estáticas. No usa cookies ni rastreadores. Está alojado en GitHub Pages, y GitHub puede registrar datos técnicos, como direcciones IP, según se describe en la Declaración general de privacidad de GitHub.

Solicitudes de eliminación de datos

Como no se recopila nada, no hay nada para eliminar. Si tenés alguna consulta, escribí a gregoriodangelo@gmail.com.

Cambios en esta política

Si esta política cambia, se actualizará en esta página con una nueva fecha de vigencia.
